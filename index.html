1. Background and Mechanism Confounding Issue

The fuel injection system is a critical component for maintaining combustion performance and operational safety in marine diesel engines. Subjected to continuous mechanical stress and cyclic thermal loads, injectors frequently develop nozzle-hole clogging of varying severity. Conventional data-driven diagnostic approaches typically focus on steady-state responses while overlooking temporal dependencies within the control loop.

Under marine operating conditions, vessels undergo frequent maneuvering operations such as acceleration and deceleration. It has been observed that rotational speed variations caused by maneuvering actions induce dynamic response trends in the state signals (e.g., mass flow rate) that resemble those caused by injector clogging: both factors lead to a reduction in peak injection quantity and a prolongation of injection tailing. Conventional diagnostic models are consequently prone to confounding regular decelerations with injector degradations, resulting in false alarms.

The model accounts for the dynamic interactions among the camshaft, lift pump, individual injection pumps, high-pressure pipes, and fuel injectors.

3. CA-DANN Methodology

To resolve the distribution shift induced by variable working conditions and to capture the asymmetric coupling between control actions and state measurements, the Control-Aware Domain Adversarial Network (CA-DANN) is proposed. The architecture consists of a dual-branch feature extractor, a clogging degree classifier, and a maneuvering-regime discriminator.

Fig. 3. Overall structural architecture of the Control-Aware Domain Adversarial Network (CA-DANN).

3.1 Control-State Weighted Fusion Mechanism

In physical engine systems, control inputs actively govern engine dynamics while state indicators respond passively. Rather than using direct vector concatenation, CA-DANN implements an asymmetric dual-branch processing pipeline:

  • Control Feature Branch: Collects shaft angular velocity, cam velocity, and cam position. A Multi-Head Attention (MHA) block extracts inter-cylinder synchrony, followed by a Squeeze-and-Excitation (SE) channel module and a Sigmoid activation, yielding a normalized dynamic weight vector \(z_{\text{control}} \in (0, 1)\).
  • State Feature Branch: Ingests the instantaneous injection mass flow rates across the four cylinders. An LSTM network extracts the time-dependent injection dynamics, outputting the state vector \(z_{\text{state}}\).
  • Multiplicative Fusion: The unified representation is formed via element-wise multiplication: \(z = z_{\text{control}} \odot z_{\text{state}}\). The control-derived weights adaptively calibrate individual channels of the state feature map.
Fig. 4. Layer dimensions and hyperparameter configurations of the weighted fusion feature extractor.

3.2 Fine-Grained Maneuvering-Regime Adversarial Adaptation

Standard DANN employs a binary classifier to distinguish between source and target domains. To address multi-phase transient distributions across varying target regimes, CA-DANN formulates the discriminator as a \(K=7\) class maneuvering-regime classifier connected through a Gradient Reversal Layer (GRL). The overall optimization objective is defined as:

\[\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{clog}} + \lambda \cdot \mathcal{L}_{\text{regime}}\]

where \(\lambda\) is the domain regularization hyperparameter (set to 1.0). The minimax adversarial training forces the feature extractor to map samples into a subspace invariant to operational speed fluctuations.

5. Sensor Dropout and Robustness Evaluation

To verify operational reliability under onboard instrument failure modes, the trained network was evaluated against control sensor dropout, additive Gaussian noise, and actuator bias drift.

Fig. 6. Robustness evaluation under test-time signal degradation modes. (a) Diagnostic accuracy under control sensor channel dropout; (b) Accuracy versus Signal-to-Noise Ratio (SNR) for state and control signals; (c) Degradation profiles under constant bias injection.
Failure Tolerance Mechanism: In conventional models relying on input concatenation, sensor loss (zero-padding) injects numerical distortion directly into subsequent fully-connected layers, triggering severe diagnostic degradation. In CA-DANN, the control branch outputs are bounded within (0, 1) by the Sigmoid function. Incomplete control inputs cause bounded weight variations, allowing the state branch to sustain core feature representation. Under complete control sensor dropout, the architecture retains an accuracy of 81.84%.

1. 研究背景与机理混叠问题

燃油喷射系统是船用柴油机维持正常燃烧做功的关键组成部分。由于长期承受机械冲击和交变热负荷，喷油器易发生不同程度的孔隙堵塞。基于振动或热工参数的数据驱动诊断方法多针对稳态工况，未能有效利用控制回路中的时序信息。

在实际航行中，船舶频繁处于加减速等机动操作状态。研究发现，机动操作引起的转速变化与喷油嘴堵塞故障在状态响应特征上具有相似的动态趋势：二者均会引起瞬时喷油质量流量峰值的削减以及尾部喷油周期的拉长。常规数据驱动方法因未能区分驱动源，易将正常减速过程判别为喷油器物理损伤，造成误报。

3. CA-DANN 方法设计

为解决变工况分布偏移及控制-状态耦合表征问题，论文提出了控制感知域对抗网络（Control-Aware Domain Adversarial Network, CA-DANN），由双分支特征提取器、故障堵塞分类器及机动工况判别器构成。

3.1 控制-状态特征加权融合机制

柴油机物理系统中控制输入主导状态输出。常规特征拼接未能体现因果层级，CA-DANN 采用双分支并行处理结构：

  • 控制特征分支： 采集轴系角速度、凸轮速度与位移等控制信号，利用多头自注意力机制（MHA）提取多缸交互特征，经通道注意力（SE-Net）和残差结构处理后，通过 Sigmoid 函数映射为区间 (0, 1) 的权值向量 \(z_{\text{control}}\)。
  • 状态特征分支： 采集各缸喷油质量流量，利用长短期记忆网络（LSTM）提取时序演化特征 \(z_{\text{state}}\)。
  • 加权交互计算： 最终特征由两分支逐元素相乘得到：\(z = z_{\text{control}} \odot z_{\text{state}}\)。该结构利用控制信号生成的动态权值，对状态特征各通道进行选择性调制。

3.2 细粒度机动工况对抗迁移

标准 DANN 采用二分类判别器区分源域与目标域。针对目标域内部多阶段变速工况的复杂分布，CA-DANN 将判别器扩展为 \(K=7\) 分类的机动工况分类器，并通过梯度反转层（GRL）与特征提取器进行对抗训练。总损失函数定义为：

\[\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{clog}} + \lambda \cdot \mathcal{L}_{\text{regime}}\]

式中 \(\lambda\) 为域正则化系数（试验设定为 1）。该机制引导特征提取器滤除工况变化带来的干扰分量，保留与转速解耦的故障特征。

5. 信号缺失与抗噪鲁棒性验证

为验证实际传感设备发生故障时的容错能力，论文对训练完成的模型开展了传感器脱落、高斯白噪声干扰及零点漂移试验。

容错机制分析： 直接拼接输入的方法在传感器失效（数值归零）时，异常零值直接参与全连接层运算，引起输出层大幅波动；CA-DANN 中控制分支输出经 Sigmoid 函数约束于 (0, 1) 范围，输入失效时权重仅发生有限平移，状态分支仍可保持主体特征提取能力。在凸轮轴控制信号完全丢失的测试中，该结构仍保留 81.84% 的诊断准确率。
